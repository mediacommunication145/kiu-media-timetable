If you are from another department, this timetable is not for you. Select your degree program, semester, section and day, then press Show Classes.

📢 Important Announcement

Write an important message for students. It pops up for every student who opens the website, and it removes itself automatically after 24 hours. You can also delete it earlier if you want.

Leave both times empty for the normal way: the announcement shows right away and removes itself after 24 hours. If you set the times, it shows only between those times (for example, from 9:00 AM to 3:00 PM).

⚠ Timetable Clashes

If two classes fall at the same time for the same class group, the same classroom or the same teacher, they are listed here so the office knows right away. The same warning also appears when a class is saved.

🎓 CR Access — Class Representative Codes

Each class (program + semester) has one CR code. Give the code to that class's CR (Class Representative) — with it, the CR logs in from the "CR Login" button and marks whether today's classes were held or not. Making a new code stops the old one from working.

📋 Class Report — by CRs

Which classes were actually held, as reported by the class CRs. Pick any date to check an old report — reports are kept for 6 months. "Pending" means that class's CR has not reported yet.

Admin — Timetable Management

Add, edit or delete class entries. Changes are saved permanently and students see them right away.

Import from Excel / CSV / PDF / Word

Upload your Excel sheet (.xlsx), a CSV, a PDF, or a Word file (.docx). The classes from the file REPLACE the whole current timetable — the old classes are removed. For PDF and Word, the timetable must be in a proper table with these columns: Program, Semester, Section, Day, Start, End, Subject, Teacher, Classroom (Start/End like 09:00 and 10:30, or a single Time column like 09:00-10:30).

Sheet Upload — Handwritten / Image / PDF / Excel

Upload a timetable in any shape — an Excel file, a typed PDF, or a photo/scan of a handwritten page. Excel and typed PDFs are read right here into the preview box below: check or adjust the rows, then import with one click. A handwritten or photo sheet cannot be auto-read by the website alone — it is saved under Pending Sheets; send the same sheet to Muse in chat and it will be read, adjusted and returned as a ready-to-import file.

Pending Sheets — handwritten / photo sheets waiting to be read & adjusted

Timetable PDF / Image

Upload the department's official timetable as a PDF or an image (photo / scan). Students will get a View / Download button for this file on the student page. For automatic, searchable class entries, use the CSV import above.

Admin Password & Recovery

Change your admin password here. Also save your own recovery key — if you ever forget the password, you can reset it from the login page with this key.

Data Backup

Download a full backup of this timetable system — all classes, teachers and the saved password/recovery settings (passwords stay hashed). Keep the file somewhere safe. If the server is ever lost, restore from this file and everything comes back. (Uploaded PDF/sheet files themselves live on the server disk and are not inside this backup.)

Degree Programs

The two department programs are already added. You can add more programs later if the department starts new ones.

Teachers

Add teachers with their details — only the name is required; Designation and Email are optional and can be added later with Edit. An added teacher appears in the "For Teachers" list and in the Teacher field when you add a class — even before they have any class. Changing a teacher's name also updates their existing classes. Teacher details stay private — students never see them.

Timetable Grid — Excel Style Editor

The whole week in one sheet, like the printed timetable. Tap any class to edit it right here — subject, teacher, time — or tick Confirm / Cancel — it applies to that class's next date. Tap an empty box (+) to add a class in that slot. For a one-time Extra Class (e.g. a makeup class), tick Extra Class in the editor and pick its date — students will see it only in that week, with an EXTRA CLASS tag.
